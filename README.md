# Быки и Коровы

Консольная игра: игрок и компьютер по очереди угадывают числа друг друга.

## Правила

Загадывается четырёхзначное число с различными цифрами.  
После каждой попытки сообщается:

- **быки** — цифра угадана и стоит на своём месте;
- **коровы** — цифра угадана, но стоит не на своём месте.

Первым ходит игрок. Кто угадает число соперника раньше — побеждает.

## Стратегия компьютера

Компьютер хранит список всех допустимых чисел.  
На каждом ходу он выбирает случайное число из списка, а после ответа игрока удаляет все числа, которые дали бы другой результат.  
Так список быстро сокращается до единственно верного варианта.
